========================================
  ハートピア収穫物検索 Bot 使い方ガイド
========================================

■ セットアップ手順（初回のみ）
----------------------------------------

1. Python をインストールする
   https://www.python.org/downloads/
   ※「Add Python to PATH」に必ずチェックを入れること

2. コマンドプロンプトを開き、以下を順に実行する

   git clone https://github.com/906ns/mhr-heartopia-bot.git
   cd mhr-heartopia-bot
   pip install -r requirements.txt

3. .env ファイルを作成する

   copy .env.example .env

4. .env をメモ帳で開き、DISCORD_TOKEN= の後に
   Bot トークンを貼り付けて保存する


■ Bot の起動
----------------------------------------

   cd mhr-heartopia-bot
   python bot.py

 ・「Bot 起動完了」と表示されたら OK
 ・止めたいときは Ctrl + C を押す


■ 使い方
----------------------------------------

 1. Discord のチャンネルで「魚」「虫」「鳥」のいずれかを送信する
    （ひらがなの「さかな」「むし」「とり」でも OK）
 2. 天気ボタン（☀️晴 / 🌧️雨 / 🌈虹）を選択する
 3. 結果がレベル順に一覧表示される
 4. 件数が多い場合は「前へ / 次へ」ボタンでページ送りできる


■ 注意事項
----------------------------------------

 ・Bot を動かしている PC の電源を切ると Bot も止まる
 ・.env ファイル（トークン入り）は絶対に他人に共有しない
 ・Discord Developer Portal で「MESSAGE CONTENT INTENT」がオンになっている必要がある
 ・「魚」「虫」「鳥」（または「さかな」「むし」「とり」）だけのメッセージに反応する（「魚釣りたい」等には反応しない）
 ・ボタンは120秒で無効化される。再検索したい場合はもう一度送信する
 ・データは data/harvest.json に入っている。ゲームアプデで変わった場合は手動更新が必要
